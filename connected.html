hop Connected

A one-off setup in Shopify, done once. About five minutes.

A job for whoever looks after the website

Before we can collect and deliver your orders, Shopify needs permission to tell us when one comes in. This is the one-off setup that gives it. About five minutes, and you only do it once.

It is not done in your usual store admin

Shopify closed that route on 1 January 2026. It is now done in a separate place called the Dev Dashboard, which you reach from your Shopify account. It looks like a developer tool, because it is one. You only need four screens of it.

You need to be signed in to the Shopify account that owns the store.

Setting it up

1

Open the Dev Dashboard

Go to dev.shopify.com/dashboard and sign in with the Shopify account. Open Apps on the left.

2

Create the app

Select Create app at the top right, then Start from Dev Dashboard. Name it something like Cyclone Deliveries and select Create.

3

Add three permissions, then release

Open the Versions tab. Add these three, leave everything else as it is, and select Release.

read_orders
write_merchant_managed_fulfillment_orders
write_assigned_fulfillment_orders

This is the step that catches people. The permissions live on a version, and nothing works until you select Release. Skip it and everything still looks finished, but we will not be able to see the orders.

4

Install it on the store

Back to Home, scroll down, select Install app. Choose the store and select Install.

5

Copy the credentials

Open Settings and copy the Client ID and the Client secret.

What to send us

Your shop domainyour-shop.myshopify.com
Client IDa long string of letters and numbers
Client secreta longer one, usually starting shpss_
The client secret is a password

Please do not email it. Send it by phone, by text, or any way you would send a password, and tell us separately that it is on its way.

Turn on local delivery

Separate from the app, and done in the ordinary Shopify admin. Settings, Shipping and delivery, Local delivery, then the location you deliver from. Choose Use postal codes and paste in the areas we cover.

D01*, D02*, D03*, D04*, D05*, D06*, D6W*, D07*, D08*, D09*, D10*, D11*, D12*, D13*, D14*, D15*, D16*, D17*, D18*, D20*, D22*, D24*, A94*, A96*, K67*

Then set the delivery fee. That is what the customer pays the shop, and it is the shop’s to decide. It has nothing to do with what we charge them.

That list is what decides who is offered delivery at checkout. Somebody outside those areas will not see it, which is what keeps orders to places we can actually reach. If the shop delivers somewhere not on the list, tell us rather than adding it.

What we do next

We register to receive notifications from the store. There is nothing else for anyone to do.

Please do not set up any notifications on your side

They will not work. We register them from our end, using the credentials above.

After that the order number, delivery address and phone number come through to us. You will know it is working because the order is marked as fulfilled in the Shopify admin, with a Cyclone tracking number on it.

When orders reach us

Two ways, and we agree which one before the shop goes live.

When the order is placed

A qualifying order comes to us as soon as the customer checks out, and we book the collection straight away. Right if everything the shop sells is in stock and ready to go.

When you mark it ready for delivery

Nothing reaches us until somebody opens the order in Shopify and clicks Mark as ready for delivery. That click is what starts the collection, so an order nobody marks is an order we never collect. Right if an order might be waiting on stock, on payment, or on somebody picking it.

Either way we only take orders where the customer chose Local Delivery at checkout and the address is inside the area above.

If you get stuck

The Dev Dashboard does not look like the shop

It should not. It is a separate place, and the link in step 1 goes straight there.

There is no Install app button

A version has almost certainly not been released. Back to the Versions tab, check the three permissions are listed, and select Release.

The client secret has disappeared

Shopify may only show it once. Generate a new one in Settings if it is gone, and tell us, because the old one stops working the moment you do.
