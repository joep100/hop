If a link gives you a 404

The filename in the repo does not match the link. Open the Vercel deployment, look at the file list it built from, and change the href here to whatever the file is actually called.

Only index.html serves at the bare domain. Everything else needs its filename in the URL, so this page has to sit at /mockups.html rather than at the root.
